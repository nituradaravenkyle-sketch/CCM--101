# Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I think compute resources are one of the most important cloud infrastructure components because they provide the processing power needed to run applications and services. Without compute resources, applications would not be able to perform their tasks properly. It works together with other components to support different workloads.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by managing important resources such as the CPU, memory, storage, and networking. During this laboratory, I used different Linux commands in the KillerCoda environment to check the operating system, CPU, memory, storage, hostname, and IP addresses of the virtual server.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it provides a clear record of the infrastructure, configurations, and decisions made before deployment. It can help developers and engineers understand the environment, identify possible problems, and properly plan the cloud infrastructure.

## 4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux server using commands such as `lscpu`, `free -h`, `df -h`, `hostname`, and `hostname -I`. I also learned how to document infrastructure information using Markdown, compare cloud provider services, create a simple cloud architecture diagram, and organize my work using GitHub.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio has improved because I added a complete cloud infrastructure laboratory project with organized Markdown documentation and a cloud architecture diagram. I also practiced making meaningful commits and organizing files into the proper folders. This helped make my repository more organized and easier to understand.

## Conclusion

This laboratory helped me understand how compute, storage, networking, and operating systems work together in a cloud environment. It also showed me that technical documentation is an important part of planning and managing cloud infrastructure. Overall, the activity gave me practical experience with Linux commands, cloud concepts, Markdown, and GitHub.
