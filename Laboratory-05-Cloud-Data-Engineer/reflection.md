# Reflection

## Cloud Data Engineer Role

This activity helped me understand the importance of cloud storage in managing and organizing data. As a Cloud Data Engineer, I learned that choosing the right type of storage depends on the kind of data and how it will be used.

I learned about three common types of cloud storage: object storage, block storage, and file storage. Object storage is useful for large amounts of unstructured data such as images, videos, backups, and data lake files. Block storage is commonly used for virtual machines and databases that need fast and consistent access. File storage is useful when different users or applications need to access shared files and folders.

I also learned that cloud storage is not just about saving data. It is important to consider the storage requirements, accessibility, performance, and purpose of the data before choosing a storage solution.

Overall, this activity gave me a better understanding of how cloud storage supports data management. The knowledge I gained can be useful for my future projects and can help me understand the responsibilities of a Cloud Data Engineer.
