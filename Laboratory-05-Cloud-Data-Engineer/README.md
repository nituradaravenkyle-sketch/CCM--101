# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory focuses on cloud object storage using MinIO. The mission involves understanding different types of cloud storage, deploying an S3-compatible object storage server using Docker, creating a storage bucket, and uploading a sample object.

## Objectives

- Differentiate between Block, File, and Object Storage.
- Deploy an S3-compatible Object Storage server using Docker.
- Access a cloud service through port forwarding.
- Create a storage bucket and upload objects.
- Document cloud storage operations using Markdown.
- Continue developing a professional GitHub Cloud Computing Portfolio.

## Tools Used

- KillerCoda Playground
- Ubuntu Linux
- Docker
- MinIO
- GitHub
- Web Browser
- Markdown

## Skills Learned

- Understanding cloud storage types
- Using Docker to deploy cloud services
- Working with Linux command-line commands
- Understanding object storage and buckets
- Using port forwarding to access web services
- Creating technical cloud documentation
- Managing a GitHub Cloud Computing Portfolio
