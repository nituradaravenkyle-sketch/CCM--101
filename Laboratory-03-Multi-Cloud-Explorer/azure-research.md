# Microsoft Azure Research

## 1. Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides cloud services that organizations can use to build, deploy, manage, and scale applications and IT infrastructure. Azure offers services for computing, storage, networking, databases, security, analytics, artificial intelligence, and application development.

## 2. Global Infrastructure

Azure provides a global cloud infrastructure consisting of geographic regions and data centers around the world. Azure regions allow organizations to deploy applications and services in different geographic locations. Azure also provides availability zones in supported regions to help organizations design applications with improved availability and resiliency.

## 3. Cloud Management Console

The Azure portal is Microsoft's web-based management interface for Azure services. It provides a graphical interface where users can create, configure, monitor, and manage Azure resources. The portal also provides access to services, resource groups, dashboards, subscriptions, and other cloud management features.

## 4. Four Core Services

### Azure Virtual Machines

Azure Virtual Machines provide scalable virtualized computing resources that allow organizations to run applications and operating systems in the cloud.

### Azure Blob Storage

Azure Blob Storage is an object storage service designed to store large amounts of unstructured data such as documents, images, videos, backups, and application data.

### Azure Virtual Network

Azure Virtual Network allows organizations to create private networks in Azure and securely connect cloud resources to each other and to on-premises environments.

### Azure SQL Database

Azure SQL Database is a managed relational database service based on Microsoft SQL Server technology. It allows organizations to run SQL databases without managing the underlying database infrastructure themselves.

## 5. Three Advantages

1. **Strong Microsoft integration** – Azure integrates closely with Microsoft technologies such as Windows Server, Microsoft 365, Active Directory, and SQL Server.
2. **Global infrastructure** – Azure provides cloud regions and data centers across many geographic locations.
3. **Enterprise capabilities** – Azure provides services for security, identity, networking, databases, analytics, artificial intelligence, and hybrid cloud environments.

## 6. Typical Enterprise Use Cases

Azure is commonly used by enterprises for hosting applications, Windows Server workloads, databases, virtual machines, Microsoft-based business systems, data analytics, artificial intelligence, backup, disaster recovery, and hybrid cloud solutions. Organizations that already depend heavily on Microsoft technologies can integrate their existing infrastructure with Azure services.
