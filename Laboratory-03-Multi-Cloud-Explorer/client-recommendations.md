# Cloud Platform Recommendations

## Client A – Startup Company

### Recommended Platform: Amazon Web Services (AWS)

AWS is recommended because it provides a wide range of services that can help a startup build and launch a mobile application without needing to manage physical infrastructure. The startup can begin with smaller resources and scale them as the number of users grows. AWS also provides many managed services that can reduce the amount of infrastructure management required by a small development team.

### Recommended Services

- **Amazon EC2** – Provides virtual computing resources for application workloads.
- **Amazon S3** – Provides scalable object storage for files, images, backups, and application data.
- **Amazon RDS** – Provides managed relational database services for application data.
- **Amazon CloudFront** – Can distribute application content to users through a global content delivery network.

---

## Client B – University

### Recommended Platform: Microsoft Azure

Azure is recommended because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies, making migration and identity management easier. The university can connect its existing on-premises infrastructure with Azure and gradually move selected workloads to the cloud instead of migrating everything at once.

### Recommended Services

- **Azure Virtual Machines** – Can host Windows Server workloads in the cloud.
- **Microsoft Entra ID** – Provides cloud-based identity and access management.
- **Azure SQL Database** – Provides a managed SQL database service.
- **Azure Virtual Network** – Provides networking for Azure resources and connections to existing infrastructure.

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform (GCP)

Google Cloud is recommended because the company focuses on Artificial Intelligence and Machine Learning workloads that require high-performance computing. Google Cloud provides infrastructure and services designed for AI and machine learning development. Its data analytics capabilities and Kubernetes platform can also support research workloads and scalable AI applications.

### Recommended Services

- **Compute Engine** – Provides virtual machines for high-performance computing workloads.
- **Google Kubernetes Engine (GKE)** – Provides managed Kubernetes for containerized AI applications.
- **Vertex AI** – Provides tools and services for developing and deploying machine learning models.
- **Cloud Storage** – Provides scalable storage for datasets, models, and research files.

---

## Client D – Global E-Commerce Company

### Recommended Platform: Amazon Web Services (AWS)

AWS is recommended because the company operates globally and requires highly available and scalable infrastructure. AWS provides multiple Regions and Availability Zones that can help organizations design resilient applications. AWS also provides services that automatically scale computing resources and distribute application traffic across infrastructure. These capabilities make AWS suitable for a large international e-commerce platform.

### Recommended Services

- **Amazon EC2** – Provides scalable computing resources for web and application servers.
- **Elastic Load Balancing** – Distributes incoming application traffic across multiple resources.
- **Amazon EC2 Auto Scaling** – Automatically adjusts computing capacity based on workload requirements.
- **Amazon RDS** – Provides managed relational database services for e-commerce data.
- **Amazon CloudFront** – Helps deliver web content to users through a global content delivery network.

# Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | Provides a broad selection of services and scalable infrastructure suitable for growing applications. |
| Enterprise Organization | AWS | Offers a large ecosystem of services that can support diverse enterprise workloads. |
| Microsoft Environment | Azure | Provides strong integration with Windows Server, Microsoft 365, and Microsoft identity technologies. |
| AI / Machine Learning | Google Cloud | Provides strong AI and machine learning services and infrastructure. |
| Kubernetes Deployment | Google Cloud | Google Kubernetes Engine provides a managed Kubernetes platform for containerized applications. |
| Global Web Application | AWS | Provides extensive global infrastructure and services for scalable and highly available applications. |
